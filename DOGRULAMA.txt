Vocrec2 doğrulama

- .NET SDK 9.0.317 ile çözüm derlendi; .NET 8 kurulumu gerekmez.
- Windows hedefli çözüm Release derlemesi: 0 hata, 0 uyarı.
- Platform bağımsız testler (Bearer token dahil): 51/51 geçti.
- Testler: mevcut mixer/kaynak seçimi; mikrofon uğultu, arka plan,
  konuşma kazancı, stereo ve tepe sınırı; STT metninin LLM öncesi
  yazılması; LLM istek/yanıt formatı; HTTP hatasında metnin korunması;
  URL doğrulama ve ayarların JSON kalıcılığı; isteğe özel Bearer başlığı,
  token silindiğinde başlığın kaldırılması, hatalı token doğrulaması.
- Windows x64 bağımsız paket üretildi; gerekli STT/FFmpeg dosyaları
  paket yerleşiminde kontrol edilir.
- Önceki sürümde Windows runner üzerinde 12 Windows AAC/kayıt testi geçti.
  Bearer token sürümünde bunlara 3 DPAPI/kalıcılık testi eklendi;
  güncel Windows test sonucu GitHub Actions üzerinden doğrulanır.
- global.json .NET 9.0.x SDK seçer. Tüm projeler net9.0 / net9.0-windows
  hedefler. Kullanıcının SDK 9.0.317 sürümü için ayrı Windows derleme
  kontrolü GitHub Actions akışında yer alır.
- Manas model ağırlıkları yok; gerçek STT ve fiziksel mikrofon dinleme
  testi yapılmadı. Qwen servisi sağlanmadığından REST testleri sahtedir.
- GitHub erişimi güncellendikten sonra kaynak kod
  https://github.com/hakancuraci/Vocrec2 main dalına gönderildi.
  Windows testlerinin güncel sonucu GitHub Actions üzerinden izlenebilir.

- Klasörlerin kapanışta korunması, çoklu profil seçimi ve token ayrımı için
  Windows arayüz testleri eklendi. Özet adı çağrısında hata sonrası devam,
  dosya çakışması ve güvenli 5 kelimelik ad kuralları test edildi.

- Açılır menünün seçim yapmadan tekrar açılıp kapanması ve açık menüyle
  pencerenin kapatılması için Windows UI Automation regresyon testleri eklendi.
- Otomatik GitHub Release yayını kaldırıldı. Derleme, test ve Windows
  Actions paketi korunur. Sürüm Version.props dosyasından alınır;
  EXE sürümü, paket configi ve kaynak commit kimliği CI içinde karşılaştırılır.

- STT çıktıları .md, LLM özetleri .ozet.md olarak UTF-8 kaydedilir.
  Eski TXT önbellekleri ve tamamlanmış iş durumları Markdown çıktısına
  yeniden STT/LLM çağrısı gerektirmeden taşınarak devam edebilir.

- Boş prompt alanına ve önceden kaydedilmiş uzun prompt üzerine gerçek
  Windows panosundan çok satırlı/tek satırlı uzun metin yapıştırma,
  temizleme, yeniden yapıştırma ve kapanış sonrası geri yükleme testleri
  eklendi. Düzenleme sırasında native metin kutusu yeniden oluşturulmaz.

- İsteğe bağlı kayıt adı kayıt sırasında düzenlenebilir. Ses, metin ve özet
  ortak adı kullanır; doluysa LLM dosya adı çağrısı atlanır. Boşsa mevcut
  otomatik adlandırma sürer. Bekleyen işlerde adlandırma tercihi korunur.
  Ad temizleme, dosya çakışmaları ve kayıt sırasında değiştirme testleri eklendi.

- Yeni ses/STT/özet dosyalarında ggAAYY_ tarih ön eki kullanılır. Tarih
  kaydın başladığı gün alınır; elle/LLM adlandırmasında, eski tarihli
  kayıtların yeniden işlenmesinde ve bekleyen işlerde korunur.
  Yinelenen ön ek, uzun elle ad, eski otomatik ad ve çakışma testleri eklendi.

- Kayıt sürerken otomatik/elle mod geçişleri ve canlı mikrofon/çıkış
  ekleme-kaldırma açıldı. Elle seçim otomatik keşfi kapatır; geç gelen
  taramalar seçimi geri almaz. Tüm kaynaklar kaldırılınca sessizlikle devam eder.
- Özetler kayıt gününe ait ggAAYY alt klasöründe toplanır. Aynı gün,
  farklı gün, çakışma ve eski tamamlanmış işin LLM'siz devamı testleri eklendi.

- Özet Markdown dosya adından tarih ön eki kaldırıldı; tarih yalnız
  günlük klasörde kalır. Ses ve STT metni adları kayıt tarihini korur.
